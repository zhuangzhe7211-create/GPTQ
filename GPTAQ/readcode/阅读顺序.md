# GPTAQ 代码阅读顺序

先读懂 GPTQ 的 `add_batch()` 和 `fasterquant()`，再读本项目。第一轮只看 `code/fake_quant/`。

1. [main.py](../code/fake_quant/main.py)：看 `main()`，找到 `args.asym_calibrate` 如何选择 GPTAQ 分支。
2. [utils.py](../code/fake_quant/utils.py)：看 `parser_gen()`，弄清权重位宽、激活位宽、校准开关。
3. [model_utils.py](../code/fake_quant/model_utils.py)、[data_utils.py](../code/fake_quant/data_utils.py)：看模型和校准数据怎么加载。
4. [quant_utils.py](../code/fake_quant/quant_utils.py)：先读 `WeightQuantizer`，再读 `ActQuantizer` 和 `ActQuantWrapper`。
5. [gptq_utils.py](../code/fake_quant/gptq_utils.py)：快速回顾基线的逐层校准和误差补偿。
6. **[gptaq_utils.py](../code/fake_quant/gptaq_utils.py)**：先看 `gptaq_fwrd()` 的两条输入路径，再看 `GPTAQ.__init__()` → `add_batch()` → `fasterquant()`；重点追踪浮点参考输入与量化路径输入的差异如何进入补偿。
7. [main.py](../code/fake_quant/main.py)：回看 `add_aq()` 和 `enable_aq_calibration`，理解激活量化是在校准前还是校准后开启。
8. [eval_utils.py](../code/fake_quant/eval_utils.py)：看困惑度评估。
9. 最后读 [rotation_utils.py](../code/fake_quant/rotation_utils.py)、[hadamard_utils.py](../code/fake_quant/hadamard_utils.py)，理解旋转预处理。

第一轮跳过 `spinquant/`、`vit_quant/`，它们是其他实验路线。注意：asymmetric calibration（非对称校准）和带 zero-point 的非对称数值量化不是同一个概念。

## 核心文件具体做什么

| 文件 | 作用 |
|---|---|
| `fake_quant/main.py` | 总入口：解析参数，选择GPTQ/GPTAQ校准分支，安装激活量化包装并启动评估。 |
| `fake_quant/utils.py` | 定义命令行参数和公共设置，决定权重/激活位宽、分组、旋转和校准方式。 |
| `fake_quant/model_utils.py` | 加载模型、寻找线性层，并提供逐层移动和替换模型组件的工具。 |
| `fake_quant/data_utils.py` | 加载并整理校准集与困惑度测试集。 |
| `fake_quant/quant_utils.py` | 量化基础：计算scale/zero，模拟权重和激活量化，并包装需要量化的层。 |
| `fake_quant/gptq_utils.py` | GPTQ基线，用输入统计构造二阶信息并逐层量化、补偿误差。 |
| `fake_quant/gptaq_utils.py` | GPTAQ核心：同时利用浮点参考路径与量化路径的输入，执行非对称校准和补偿。 |
| `fake_quant/eval_utils.py` | 计算量化模型的困惑度或下游任务结果。 |
| `fake_quant/rotation_utils.py` | 把等价旋转融合进模型权重，改善量化前的数值分布。 |
| `fake_quant/hadamard_utils.py` | 提供Hadamard变换及相关矩阵运算。 |

`fake_quant/`是第一遍的主体；`spinquant/`是旋转量化实验，`vit_quant/`是视觉模型分支，`deployment/`或底层内核应放到最后。

本文件依据本地源码整理；未安装依赖或运行量化实验。
