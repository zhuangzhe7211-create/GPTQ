# GuidedQuant 代码阅读顺序

仓库有多条实验路线。第一轮选 `LNQ + GuidedQuant`，不要同时读全部子目录。

1. [README.md](../code/README.md)：只读 `Weight-only scalar quantization` 的流程说明。
2. [scripts/run_sqllm.sh](../code/scripts/run_sqllm.sh)、[scripts/run_lnq.sh](../code/scripts/run_lnq.sh)：看梯度准备、初始量化和后续 LNQ 分别运行哪个入口。
3. [quantize.py](../code/quantize.py)、[layerwise_nuq.py](../code/layerwise_nuq.py)：看参数如何传入量化流程。
4. [any_precision/quantization/main.py](../code/any_precision/quantization/main.py)、[layerwise_main.py](../code/any_precision/quantization/layerwise_main.py)：看各阶段、缓存及中间结果的组织。
5. **[gradients.py](../code/any_precision/quantization/gradients.py)**：看 `get_gradients()`，追踪权重梯度、激活梯度和 `num_groups`；理解指导信息从哪里来。
6. [activations.py](../code/any_precision/quantization/activations.py)：看激活统计和 Hessian 收集。
7. **[layerwise_quantize.py](../code/any_precision/quantization/layerwise_quantize.py)**：按 `objective_function()` → `update_P()` → `update_C()` → `train_least_squares()` → `seed()` 阅读，理解目标函数和码本/分配更新。
8. [pack.py](../code/any_precision/quantization/pack.py)、[run_eval.py](../code/run_eval.py)：看结果打包和评估。
9. 最后读 [inference_example.py](../code/inference_example.py)，理解实际生成路径。

如果你只想从 GPTQ 接着学：另选 [spin_quant/eval_utils/main.py](../code/spin_quant/eval_utils/main.py) → [gptq_utils.py](../code/spin_quant/eval_utils/gptq_utils.py) → [gptq_guided_utils.py](../code/spin_quant/eval_utils/gptq_guided_utils.py) 这条对照路线。第一轮跳过 `qtip/` 和 CUDA 推理内核。

## 核心文件具体做什么

| 文件 | 作用 |
|---|---|
| `scripts/run_sqllm.sh` | 准备基础量化实验的命令和参数。 |
| `scripts/run_lnq.sh` | 启动加入GuidedQuant信息的逐层非均匀量化。 |
| `quantize.py` | 全局量化入口，把模型、数据、位宽和输出位置交给量化模块。 |
| `layerwise_nuq.py` | 逐层非均匀量化入口，组织每层统计、优化和结果保存。 |
| `any_precision/quantization/main.py` | Any-Precision量化主流程，协调梯度、激活和码本计算。 |
| `layerwise_main.py` | 把上述流程细化到每个Transformer层并管理中间缓存。 |
| `gradients.py` | 收集权重或激活梯度，形成GuidedQuant使用的任务相关指导信号。 |
| `activations.py` | 通过校准输入收集激活和Hessian近似统计。 |
| `layerwise_quantize.py` | 核心优化：计算目标函数，并交替更新分配与量化中心。 |
| `pack.py` | 把优化后的量化值和索引整理为可保存/加载的格式。 |
| `run_eval.py` | 加载量化结果并运行困惑度或任务评估。 |
| `inference_example.py` | 展示压缩模型的实际加载和生成调用。 |

`any_precision/quantization/`是本路线的算法主体；`spin_quant/`是与GPTQ相接的另一条实验路线；`qtip/`及CUDA代码用于其他量化或部署路径，第一遍跳过。

本文件依据本地源码整理；未运行实验。
