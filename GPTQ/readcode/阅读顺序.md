## 文件具体的用途

/zeroShot: 就是不给模型提供“示例题 + 答案”，直接让它进行答题

* ZeroShot
* Few-Shot: 先给几道例题和答案，再问新的题目

这里的零样本指的是提示词中任务示例的数量为0，量化时仍然可以使用校准数据

用途：测试模型量化之后做问答，常识推理等任务的能力有没有下降

zeroShot/ 的用途：测试模型量化之后，做问答、常识推理等任务的能力有没有下降。

| `zeroShot/` 下的文件 | 用途 |
|---|---|
| `main.py` | **程序入口**：选择任务、启动评估、输出结果。 |
| `evaluator.py` | **评估总流程**：加载模型、执行量化、运行题目、汇总成绩。 |
| `datautils.py` | 加载 GPTQ **量化校准数据**，如 WikiText2、C4。 |
| `metrics.py` | 计算准确率、F1、困惑度、标准误差等指标。 |
| `utils.py` | 解析命令行参数、匹配任务名称等辅助工作。 |
| `README.md` | 使用说明和运行命令。 |
| `LICENSE.md` | 许可证说明。 |

models/ 负责加载模型、量化模型、调用模型

| 文件 | 用途 |
|---|---|
| `__init__.py` | 根据模型名称选择 OPT 或 BLOOM。 |
| `opt.py` | 将 OPT 接入评估框架，包含加载、分词、推理和逐层量化。 |
| `bloom.py` | 与上一项类似，适配 BLOOM。 |
| `models_utils.py` | 模型公共接口，以及答案概率计算、分批处理等工具。 |
| `gptq.py` | GPTQ 核心：收集输入统计、量化权重、补偿误差。 |
| `quant.py` | 量化参数和舍入计算，也包含激活量化包装、4-bit 线性层代码。 |
| `fast_trueobs.py` | 另一份二阶量化实现，包含保留异常权重等选项；当前主流程没有引用，可以先跳过。 |

tasks/ 负责准备题目、组织提示词、判断答案：

| 文件 | 用途 |
|---|---|
| `__init__.py` | 任务注册表：把 `piqa` 等名称对应到具体任务类。 |
| `tasks_utils.py` | 所有任务共用的基础代码：读取数据、拼接示例、请求模型打分等。 |
| `piqa.py` | 生活物理常识题：从两个解决方案中选一个。 |
| `arc.py` | 科学常识选择题，分 Easy 和 Challenge。 |
| `lambada.py` | 根据一段上下文预测最后一个词。 |
| `storycloze.py` | 阅读故事，选择合理的结尾。 |
| `glue.py` | GLUE 语言理解任务，例如判断一句话能否推出另一句话。 |
| `superglue.py` | SuperGLUE 任务，例如因果选择、指代消解、阅读理解。 |

tasks/local_datasets/ 负责部分数据集的加载和本地数据：

| 文件 | 用途 |
|---|---|
| `__init__.py` | 导入数据集模块。 |
| `lambada/__init__.py` | 导出 LAMBADA 数据集加载类。 |
| `lambada/lambada.py` | 下载、读取 LAMBADA 原始数据。 |
| `lambada/dataset_infos.json` | 数据集的字段、大小等元信息。 |
| `storyCloze2018/…csv` | StoryCloze 的实际题目数据。 |

zeroshot外部的文件：

| 文件 | 做什么的 | 阅读优先级 |
|---|---|---|
| **`opt.py`** | OPT 模型的运行入口：加载模型 → 量化 → 评估，也包含保存和速度测试。 | **先读，了解流程** |
| **`gptq.py`** | GPTQ 核心算法：收集输入统计、逐列量化、补偿误差。 | **重点读** |
| **`quant.py`** | 计算 `scale`、`zero`，执行舍入量化；后半部分负责 3-bit 权重打包和推理。 | **先读前半部分** |
| `datautils.py` | 加载 WikiText2、PTB、C4，准备校准和评估数据。 | 了解即可 |
| `modelutils.py` | 设置计算设备，递归寻找模型中需要量化的线性层等模块。 | 很短，顺手读 |
| `llama.py` | LLaMA 模型的加载、量化和评估，包含 `true-sequential` 等功能。 | OPT 看懂后读 |
| `bloom.py` | BLOOM 模型的加载、量化和评估。 | 用到 BLOOM 再读 |
| `quant_cuda_kernel.cu` | 真正执行 3-bit 权重矩阵与浮点向量乘法的 GPU 代码。 | 最后读 |
| `quant_cuda.cpp` | 把 CUDA 计算函数暴露给 Python 调用。 | 最后读 |
| `setup_cuda.py` | 编译、安装上述 CUDA 扩展。 | 需要加速推理时看 |
| `test_kernel.py` | 对比普通计算与 3-bit CUDA 计算的速度，并检查计算结果。 | 最后读 |
| `README.md` | 项目说明、依赖和运行命令。 | 先浏览 |
| `LICENSE` | 开源许可证。 | 无需作为算法学习内容 |
| `.gitignore` | 指定哪些文件不纳入 Git 管理。 | 跳过 |
| `.git/` | Git 版本管理数据。 | 跳过 |
