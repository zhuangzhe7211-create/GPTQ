# 第六轮协议：完整块目标的任务敏感度、成本与迁移（2026-09-27）

在任何本轮开发结果、外部测试成绩计算前固定此协议。第五轮73篇文章已被查看，本轮不再作为新测试。

## 范围和对照

- Qwen2.5-0.5B固定revision、W4/F32逐行网格、WikiText校准seed 0/1/2各64×256，开发64×256沿用前轮。
- 共6个上下文：目标层12和18的mlp.up_proj ×3seed。所有上下文使用第四轮保存的同一seed GPTQ前12块；层18前的12–17块仍浮点。这样检验同一前缀误差在两个修复位置的效果，不冒充“前18块量化”。
- layer12初始GPTQ直接复用第五轮，layer18按相同网格和当前校准输入构建GPTQ参考。只改变一个up目标，其余目标块权重及后续模型保持浮点。
- 共同优化：Adam代码空间LR=.03，有效batch256、64×4累积，192/576步检查点。所有方法同一初始权重、相同CPU随机token序列，seed=20260930+校准seed。192步对应旧预算，576步用于检验延长预算。

设Bf是浮点块输出，Rq是当前量化前缀下MLP前残差，e=Mq(Q)−(Bf−Rq)，d=896，G是原始浮点模型CE对Bf的梯度。所有损失用mean((Bf−Rq)^2)归一化。

1. block：mean(e²)，原未加权目标，192/576步。
2. token：按原make_weights得到单组rho=.1、p=1、clip10的token权重s，最小化mean(s·e²)，192/576步。权重作用于完整块，区别于早期up分支权重。
3. direction：u_t=G_t/||G_t||（零梯度取零），最小化mean(e²)+mean_t[(u_tᵀe_t)²]，192/576步。保留通道间梯度符号关系的秩一方向罚项，系数固定1，不称为真实Hessian或完整Fisher。它忽略一阶符号效应及跨token项。
4. continuous：无round的连续代码权重，同样初始化、范围裁剪、优化器、步数及block损失；只作容量/量化约束对照，不算4-bit结果。
5. gptq：初始目标参考。
6. bias：初始GPTQ不变，在块输出加校准误差均值b=mean_t(Bf−Bq)，896个额外浮点参数；一遍拟合，不是相同架构或相同训练预算。检验廉价均值修正是否足够。

每上下文10个候选，共60个。layer12的block192应复现第五轮；若出现数值差异先诊断，不随意放宽CE约束。

## 新外部评估和冻结

- 下载wojzaremba/lstm仓库固定commit的data/ptb.test.txt，保留字节SHA256。此文件是已预处理的PTB文本，按Qwen分词后的固定窗口PPL，不能与词级PTB论文PPL比较。
- 按原换行连接文本分词，不添加或替换特殊EOS；分为非重叠256token窗口，每4个相邻窗口组成一个重采样块。固定随机seed=20261001选择32个块，共128窗口/32640计分token。不是32个独立文章；块bootstrap不能完全消除跨块依赖。
- 准备时检查与历次校准、开发及已用预留的精确token窗口哈希无重叠；这不排除语义重复，也不保证模型预训练从未见过。
- 每层、每个优化族按3seed平均开发CE选192或576，冻结所有选择、源码、配置和权重哈希后，才计算PTB成绩。
- 外部测试评估各族所选、固定gptq/bias，以及固定block192与block576锚点，复用重复配置。报告所有设置，不能根据PTB重选步数。
- 配对差先平均seed，再按32个连续窗口块bootstrap10000次，附3seed方向。探索性区间不做多重比较校正；重采样块数不是token数。
- 新加权方向值得继续的门槛：相对开发所选未加权block，两层各赢至少2/3seed、相对PPL下降≥0.1%、区间上界<0。576步的收益另相对192步检查。若新加权失败但未加权跨层/语料有效，保留简单未加权方案，不为了满足预期继续调外部测试。
