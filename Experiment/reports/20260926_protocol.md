# 2026-09-26 预训练模型单模块实验协议

在查看真实模型结果前确定以下设置，不根据验证结果调参。

- 假设：梯度平方构造的分组 token 权重，能否改善固定 FP 目标的 ResComp 补偿。
- 模型：Qwen/Qwen2.5-0.5B，commit `060db6499f32faf8b98477b0a26969ef7d8b9987`。
- 数据：WikiText-2 raw，数据缓存 commit `b08601e04326c79dfdd32d625aee71d232d685c3`。
- 校准：训练集按 seed 0、1、2 分别打乱文档，每次取 32 个 256-token 窗口。
- 验证：三个实验共享 seed 0 排序的 validation 文档，64 个 256-token 窗口；每次计分 16,320 tokens。未以 test split 进行评估或选参。
- 目标：`model.layers.12.self_attn.o_proj`；之前的 12 个完整 block 的 Linear 用同一 RTN 前缀；目标 block 其余模块保持浮点。
- 固定逐行对称 4-bit 网格，4 个连续输出通道组，rho=0.5，clip=10，alpha=alpha2=0.25，damp=0.01，blocksize=128。
- CUDA，FP32 模型和激活，关闭 TF32；这是 W4 假量化精度实验，不是 W4A16 性能或压缩部署测试。
- 对照：FP、公共 RTN 前缀、RTN 目标模块、GPTQ 参考、GPTAQ 神经元分解参考、官方 ResComp 模块核心、梯度加权核心、打乱 token 权重核心。
- 主指标：共享验证窗口上的平均 CE，PPL=exp(CE)。同时观察重建误差、逐窗口配对 CE、量化权重是否改变、时间、峰值显存。
- rho=0 的分组实现必须退化为普通 ResComp。保留负结果。三个 seed 不视为三个独立验证数据集。

局限：单个模块、公共 RTN 前缀、固定超参数，没有官方完整模型基线、alpha 搜索或最终独立 test。只能判断该设置下的可运行性和初步收益。
