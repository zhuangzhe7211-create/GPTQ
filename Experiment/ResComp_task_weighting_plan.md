# ResComp 任务加权：数学推导、实现方案与实验设计

新增配套：[GPTAQ 与 ResComp 完整数学推导](GPTAQ_ResComp_derivation.md)；[今晚实验骨架及运行指南](TONIGHT.md)。新增推导区分完整残差约束解、神经元分解快速解和官方 block 实现。今晚单模块骨架使用公共 RTN 前缀，不能当作官方全模型复现。


版本：2026-09-21。面向 RTX 4080 Laptop / 12 GB 显存。本文是研究设计与独立推导，不是已经验证有效的新算法报告。

## 1. 先明确研究问题

你的想法可以准确表述为：在保持原始浮点模型输出为重建目标的前提下，使用最终任务对中间激活的敏感度，改变 ResComp 衡量重建误差的方式，使有限的量化补偿能力优先用于任务敏感的误差方向。

这个想法有合理的数学动机，但有三件事不能预先承诺：梯度平方是否足够准确地反映敏感度、加权后实际量化结果是否改善、是否优于已有相关方法。本文分别给出可证明的代数性质、待验证的近似，以及公平的实验方法。

第一版范围：权重量化、激活保持浮点（W4A16，随后 W3A16）；不加入剪枝、不训练原始模型权重、不同时改变旋转或量化网格。研究变量尽量只保留任务权重。

推荐路线：先证明实现正确，再做“固定量化前缀 + 单个目标模块”的小实验，最后扩展到整个模型。单模块成功只是初步证据，不等于全模型优于 ResComp。

## 2. 与已有工作的关系

ResComp 保持原始浮点输出作为补偿目标，并考虑层间误差和层内补偿带来的偏差。本文以这一固定目标构造加权问题。[ResComp 论文](https://arxiv.org/html/2604.07955v1)

GuidedQuant 已经研究了利用最终损失梯度加权重建误差，并通过输出通道分组降低统计量成本。因此，“梯度加权 MSE”本身不能作为这里的创新点；需要验证它与 ResComp 固定目标和补偿更新结合后的具体效果。[GuidedQuant 论文](https://arxiv.org/html/2505.07004v4)

MARR 是必须进一步核查的相关工作。需要区分“改变残差补偿强度”和“改变误差空间的度量”。两者可能相互作用，所以后面的实验安排了等预算的补偿系数搜索对照。[MARR 论文](https://arxiv.org/html/2605.17997v1)

本文后续公式是按统一符号自行推导的参考目标与解法，不能直接当作论文原公式编号，也不能声称参考求解器与官方快速程序逐位相同。

## 3. 符号、张量形状及固定目标

全文采用“每一列是一个 token 激活”的约定。阅读采用行样本约定的论文时需要转置。

| 符号 | 形状 | 含义 |
|---|---|---|
| W₀ | d_out × d_in | 目标模块原始浮点权重，始终固定 |
| W | d_out × d_in | 当前权重，含已量化部分与尚未量化但已经补偿的部分 |
| Q | d_out × d_in | 最终量化权重 |
| X_f | d_in × N | 原始浮点模型给目标模块的输入 |
| X_q | d_in × N | 已量化前缀给目标模块的输入 |
| Y₀ = W₀X_f | d_out × N | 原始浮点目标 |
| Z = QX_q | d_out × N | 候选量化输出 |
| E = Z − Y₀ | d_out × N | 输出误差 |
| G | d_out × N | 最终任务损失对浮点目标模块输出的梯度 |

这里 N 是收集的 token 数，不一定是序列数。不同序列的激活列可以拼接，但梯度应先在各自完整序列计算图上求出。样本 ID、位置、mask 必须对应。

即使激活不量化，前面层的权重量化也会导致 X_q ≠ X_f。

先忽略偏置；有偏置时可固定原偏置并计入目标，或者通过给输入增加常数行处理，不能漏掉。

固定目标的普通重建损失为

$$J_0(Q)=\frac12\|QX_q-W_0X_f\|_F^2.$$

前面的 1/2 只为消去求导中的 2，不影响最优解。量化约束写为 Q ∈ 𝒬，其中 𝒬 必须明确包含位宽、scale、zero point、量化分组等设置。

## 4. 为什么任务损失与普通 MSE 不一样

把整个模块输出按固定顺序展平成向量 z，令浮点输出为 z₀，误差为 e。保持下游参数和其他进入下游的张量不变，把最终损失视为关于 z 的函数 ℒ(z)。

在可微邻域中作二阶展开：

$$\mathcal L(z_0+e)-\mathcal L(z_0)
=g^Te+\frac12e^TH_ze+O(\|e\|^3),$$

其中 g = ∇_zℒ(z₀)，H_z = ∇²_zℒ(z₀)。如果只假设二阶连续可微，余项可写为 o(‖e‖²)；三阶有界时才使用上面的三阶量级。

普通 MSE 相当于使用单位矩阵衡量误差大小，却没有表达 H_z 中不同方向的曲率。举例：若下游只有线性变换 A，任务是平方损失

$$\mathcal L(z)=\frac12\|Az-b\|^2,$$

则 g=Aᵀ(Az−b)，H_z=AᵀA。如果 Ae=0，输出误差 e 可以很大，但这个下游损失完全不变。这是你说的“误差被后续层消除”的一个严格例子。

实际 Transformer 下游有注意力、归一化、残差和非线性，上述 A 只能是示例或局部 Jacobian。不能直接说某个小梯度通道在所有输入上都不重要。

注意：训练结束不意味着每个样本的激活梯度 g 为零。参数梯度接近零，也不意味着激活梯度逐元素为零。因此，丢弃 gᵀe 是一种额外近似，不是自动成立的等式。

如果同时量化前缀，其他旁路输入也可能变化，ℒ(z) 的展开只解释目标模块这条路径。实验中固定同一个量化前缀和其他条件，才能比较该模块的贡献。

## 5. 为什么使用梯度平方，以及它不等于什么

一个廉价的非负敏感度代理是

$$s_{it}=G_{it}^2,\qquad
J_s(Q)=\frac12\sum_{i,t}s_{it}E_{it}^2.$$

注意两种写法的对应关系：若写 ‖A⊙E‖²，则 A=|G|；若在求和中写 sE²，则 s=G²。把 s=G² 再放进平方范数会错误地得到 G⁴。

梯度平方可以与经验梯度外积矩阵联系：对样本 a，取 g_a g_aᵀ，再对样本平均，其对角线为平均梯度平方。这个矩阵半正定，适合构造稳定的非负代理。

但必须区分：

1. 梯度外积不是一般任务损失的精确 Hessian。
2. Fisher 与期望负对数似然 Hessian 的关系需要模型分布取期望及正则性条件；用真实标签计算的经验外积不自动满足这个等式。
3. LLM 某个位置的激活可能影响后续多个位置。对序列总损失求出的 G_it，不是“该位置自己的 token loss 梯度”。
4. 对角代理丢掉了跨通道、跨 token 的交叉项。
5. 若教师恰好在平方任务的最优点，g=0 而 H_z 仍可能非零。因此零梯度不代表零曲率。

第一版把它明确称为“任务敏感度代理”，通过实验验证，不写成 H_z=diag(G²) 的数学定理。

为稳定统计，先计算 a_gt=mean_{i∈I_g}(G_it²)，再在有效 token 上归一化：

$$\widetilde s_{gt}=\frac{a_{gt}}{\operatorname{mean}_{t\in valid}a_{gt}+\epsilon}.$$

随后 clip(𝑠̃,0,c)，再次归一化到有效 token 均值 1，最后混合：

$$s_{gt}=(1-\rho)+\rho\widetilde s_{gt},\quad 0\le\rho\le1.$$

padding 的 s 设为 0；若整组梯度为零，直接回退为有效 token 权重 1。建议先固定 c=10，验证集选择 ρ∈{0,0.25,0.5,1}。这些是初始实验设置，不是最优超参数结论。

## 6. 必须先证明的陷阱：每行一个常数可能完全无效

设每行独立量化，量化可行域分解为 𝒬=𝒬₁×…×𝒬_dout，且 s_it=c_i>0 与 token 无关。那么

$$J_s(Q)=\sum_i c_iJ_i(Q_i).$$

对任一行 i，正数乘法不改变大小关系：J_i(a)≤J_i(b) 当且仅当 c_iJ_i(a)≤c_iJ_i(b)。因此

$$\arg\min_{Q_i\in\mathcal Q_i}c_iJ_i(Q_i)
=\arg\min_{Q_i\in\mathcal Q_i}J_i(Q_i).$$

结论：在这些假设下，固定通道权重不改变最优解集合。普通逐行量化中，一个通道的误差也不会直接迫使另一独立行改变；所谓竞争需要共享约束、共享超参数或行内不同 token/输入方向之间的取舍。

若存在跨行共享 scale、低秩约束、预算分配等，前提不再成立。固定绝对阻尼、数值误差也可能让实现产生差别，但不能把这误认为有效的任务引导。

所以第一版必须保留随 token 变化的权重，或者显式引入行间耦合。这里优先选择前者。

## 7. 四种可以实施的方案

| 方案 | 定义及改变 | 成本 | 用途 |
|---|---|---|---|
| A：共享 token 权重 | s_t=mean_i G_it²，所有输出行使用同一 D | 每模块一套加权统计 | 最便宜的首次贯通；它不能区分通道组 |
| B：通道组 × token 权重 | 将输出行分 G 组，s_gt=mean_{i∈I_g}G_it² | 每组独立 Gram 与残差统计，可串行 | 推荐主方案，先 G=4 |
| C：任务引导候选选择 | 原 ResComp 用少量不同补偿系数生成候选，用加权验证误差挑选 | 多次量化，无需求导更新公式 | 工程快速对照；只改变候选选择，不是加权补偿 |
| D：非对角敏感度 | 对每个 token 使用 PSD 矩阵 M_t=diag(s_t)+U_tU_tᵀ | 输出行耦合，求解更贵 | 后续方向，第一版不做 |

方案 B 的“输出敏感度组”与量化器的“输入权重分组 group size”是两种概念，代码参数应分别叫 sensitivity_groups 和 quant_group_size。

建议实现顺序：A → B；C 作为控制实验；D 和剪枝放到初步结果之后。

## 8. 加权目标的精确梯度与 Hessian

取单个输出行，将它转成列向量 q∈ℝ^d，目标 y=Y₀[i,:]ᵀ∈ℝ^N。设 X=X_q，D=diag(s_i1,…,s_iN)。则

$$J(q)=\frac12(X^Tq-y)^TD(X^Tq-y).$$

逐项展开：

$$J(q)=\frac12q^TXDX^Tq-q^TXDy+\frac12y^TDy.$$

由于 D 对称，XDXᵀ 也对称，因此

$$\nabla_qJ=XDX^Tq-XDy,\qquad
\nabla_q^2J=XDX^T.$$

所以这里的 H 是**代理重建损失对某一输出行权重 q 的 Hessian**，不是最终任务损失对激活的 Hessian H_z。采用没有 1/2 的 MSE 定义，会得到 2XDXᵀ。

展开矩阵元素可以看到保留的交叉项：

$$H_{jk}=\sum_t s_{it}X_{jt}X_{kt}.$$

它一般不是对角矩阵。因此“输出误差用对角任务度量”不等于“权重空间 Hessian 也是对角矩阵”。

正半定性证明：任意 v，有 vᵀHv=(Xᵀv)ᵀD(Xᵀv)=Σ_t s_it(x_tᵀv)²≥0。若样本不能覆盖所有输入方向，它可能奇异，需要阻尼。

## 9. 保留固定浮点目标，推导完整残差

当前权重为 W，正确残差为 R=Y₀−WX_q。直接加减 WX_f：

$$R=W(X_f-X_q)+(W_0-W)X_f.$$

第一项与输入差异有关；第二项与当前权重偏离原权重有关。关键是 W₀不随补偿变化。

对一个输出组，固定该组的 D，定义原始统计量

$$H^{raw}=X_qDX_q^T,$$
$$C=(X_f-X_q)DX_q^T,$$
$$T=X_fDX_q^T=H^{raw}+C.$$

于是严格有

$$RDX_q^T=WC+(W_0-W)T.$$

这是实现的重要恒等式。不能只修改 H 而继续使用未加权的 C，也不能把 T 换成加过阻尼的 H+C。

批量累积时，每批使用相同尺度的 D，并对 H、C、T 使用同一公共归一化因子。不要对每批分别重新设为均值 1 后又宣称等于全数据归一化目标；可以先缓存原始敏感度并计算全局均值，再累积。

## 10. 一个量化步骤的完整约束解

本节提供容易验证的慢速参考求解器数学式，不声称它就是官方快速代码的逐行翻译。

已量化坐标集合为 C，尚可修改坐标集合为 F。当前完整向量 w 包含冻结的 w_C。残差必须使用完整向量：

$$r=y-X_q^Tw.$$

只允许 F 上更新 δ。令 X_F=X_q[F,:]。目标为

$$\min_\delta\frac12(X_F^T\delta-r)^TD(X_F^T\delta-r)
+\frac\lambda2\|\delta\|^2,$$

同时要求下一个坐标 k 达到固定量化值 q_k：e_kᵀδ=a，a=q_k−w_k。e_k 是 F 坐标系中的单位向量。

这里阻尼明确解释为对“本次更新 δ”的二次惩罚。每步使用这个目标，不代表在求一个固定的全局 ridge 回归问题。

记

$$H=X_FDX_F^T+\lambda I,\qquad b=X_FDr.$$

去掉与 δ 无关的常数，得到

$$\min_\delta\frac12\delta^TH\delta-b^T\delta,
\quad e_k^T\delta=a.$$

λ>0 时 H 正定。拉格朗日函数为

$$\Phi(\delta,\mu)=\frac12\delta^TH\delta-b^T\delta+
\mu(e_k^T\delta-a).$$

一阶条件 Hδ−b+μe_k=0，因此 δ=H⁻¹b−μH⁻¹e_k。定义

$$u=H^{-1}b,\qquad v=H^{-1}e_k.$$

将约束代回，u_k−μv_k=a，得到 μ=(u_k−a)/v_k，故

$$\boxed{\delta^*=u+v\frac{a-u_k}{v_k}}.$$

因为 H 正定，v_k=e_kᵀH⁻¹e_k>0，分母合法。实际用 Cholesky 和 solve，不显式求逆。

**这不只是一阶驻点，也是唯一全局最优解。** 对任一可行扰动 h，有 e_kᵀh=0。利用 Hδ*−b=−μe_k：

$$f(\delta^*+h)-f(\delta^*)
=h^T(H\delta^*-b)+\frac12h^THh
=\frac12h^THh\ge0.$$

h≠0 时严格大于 0，所以解唯一。

两个解释：u 是不强制量化时的最优残差修复；第二项是在满足量化值约束的同时，以最小二次代价调整这次修复。

若 b=0，公式退化为 δ*=aH⁻¹e_k/(H⁻¹)_kk，即通常的单坐标二阶补偿形式。符号取决于 a 定义为“量化后减量化前”，不要与相反误差定义混用。

还可完成平方，得到固定 a 的最小代价中与 a 有关的部分：

$$\frac{(a-u_k)^2}{2v_k}.$$

因此，如果允许同时选择 q_k，且其余坐标暂时连续、量化网格固定，那么该参考子问题应选最接近 w_k+u_k 的网格值。**初次接入官方代码先保持原 rounding 策略**；若改变这一点，必须另设消融，否则无法判断收益来自加权还是新 rounding。

每一步的精确子问题解不等于整个离散量化问题的全局最优解；后续坐标也要量化，会破坏“其余变量自由连续”的假设。

## 11. 三个可测试的不变量

**全一退化。** D=I 时，所有加权统计恢复普通统计。在同一参考求解器中结果应一致。在官方快速实现中也应单独验证其全一分支复现原版；两种求解器之间不要求天然一致。

**整体正数缩放。** D'=cD、λ'=cλ 时 H'=cH、b'=cb，因此 u'=u、v'=v/c，约束解完全不变。若使用 λ=η·mean(diag(Hraw))，该缩放关系成立。若 λ 固定不缩放，解可能改变。

**输入重标度等价。** 令 X'_q=X_qD^(1/2)，X'_f=X_fD^(1/2)，则

$$\|(QX_q-W_0X_f)D^{1/2}\|_F^2
=\|QX'_q-W_0X'_f\|_F^2.$$

对组内共享 D 的行，这严格等于变换输入后的普通重建。并且 X'_qX'_qᵀ=Hraw，(X'_f−X'_q)X'_qᵀ=C。这给出了很有用的接入与校验方法。

这是线性重建代理中的样本重标度；不要把重标度后的中间激活直接塞进完整 Transformer 并声称任务等价。

## 12. 为什么不能证明真实任务一定改善

可以证明：上述约束解最小化指定的加权二次子问题。不能由此推出：量化后 CE 必然低于普通 ResComp。

原因包括敏感度近似偏差、非零一阶项、较大扰动下高阶项、校准数据偏差，以及多层误差交互。

一个说明逻辑边界的条件结论是：假如对两个候选 A、B 都有 |Δℒ(Q)−κJ_s(Q)|≤ε，且 κ[J_s(B)−J_s(A)]>2ε，那么 Δℒ(A)<Δℒ(B)。证明是分别用上下界夹住两者。实际没有可靠 ε，所以它只是说明“代理排序要足够准确且改善幅度足够大”，不是本文已建立的任务保证。

我们要用未参与拟合的文本检验这种排序关系，再测最终 CE/PPL。

## 13. 如何接入现有代码

已核查的入口是 [ResComp gptaq_utils_r.py](https://raw.githubusercontent.com/list0830/ResComp/main/fake_quant/gptaq_utils_r.py)。其中维护 H、dXXT 和由两者得到的 xhat_x，并保留原始权重。第一版在独立副本添加加权统计路径，保留原版作为回归基准。

需要遵循的实施规则：

1. 权重 G 在浮点教师上独立采集并固定，不在每个量化步骤重新计算。
2. 对每组用相同 D 同时构造 Hraw、C、T；然后才给用于求解的 H 加阻尼。
3. q/k/v 即使输入相同，模块输出梯度也可能不同，所以不能无条件复用它们的加权 H；gate/up 同理。只有 D 也相同才能共享。
4. 分组计算时保持原量化 scale、zero point、列顺序和输出行对应关系。若拆分模块后重新估计量化参数，先确认它没有引入额外实验变量。
5. 原有快速分解与补偿强度系数并不自动等于第 10 节慢速精确子问题。先验证统计量，再验证全一退化，最后比较相同快速路径中的加权和未加权分支。
6. 原代码中的局部 Losses 等诊断值可能不再代表新目标，额外直接计算 J₀、J_s，不能只改日志字段来声称优化目标已经改变。
7. 官方入口含 no_grad 量化流程，梯度采集放在独立的启用梯度阶段。

实现接口建议，函数内部主要由你完成：

```python
capture_teacher(...) -> teacher_inputs, output_sensitivity, token_ids
capture_quant_prefix(...) -> quant_inputs, token_ids
build_group_weights(...) -> weights  # [G, N]
accumulate_stats(x_fp, x_quant, weights) -> H_raw, C
solve_reference_step(H_raw, b, coordinate, quant_delta, damping) -> delta
quantize_weighted_module(...) -> quantized_weight, diagnostics
evaluate_candidates(...) -> metrics
```

先做无需大模型的前三个数学接口，然后接真实张量。不要一开始把梯度采集、量化和评测全写进同一个函数。

## 14. 如何采集真正需要的梯度

任务使用校准文本的 next-token cross entropy，不需要人工标注类别。其提供的是语言建模任务引导；如果最终任务是特定领域，还需要相应数据检验迁移。

第一版每次只采集一个目标模块：

1. model.eval()，use_cache=False，所有模型参数 requires_grad_(False)。
2. 在目标 Linear 的输出 hook 中，将数值输出替换为 out.detach().requires_grad_(True)，保存该张量 z，并返回它。仅适用于输出是 Tensor 的目标模块；其他结构需专门处理。
3. 在启用 autograd 的环境继续下游前向，计算真实文本 CE。
4. 使用 autograd.grad(loss,z) 获取 G。无需 optimizer.step，也不计算模型参数梯度。
5. 立刻 detach、转 CPU、清理图和 hook，处理下一序列。

不要把整个流程放在 inference_mode 或 no_grad 内；也不要同时在多个层 detach，否则会切断早期目标到损失的路径。

显式计算 next-token CE 时只移位一次：logits[..., :-1, :] 对 labels[..., 1:]。若调用模型内置 loss，应先确认其已经移位。padding 标签屏蔽。固定序列长度或使用一致的 loss reduction，避免长短样本使平方梯度尺度无意变化。

教师和学生完全一致时，它们之间 KL 对学生输出的梯度为零，因此不要用这个零梯度初始化敏感度。这里用真实文本 CE；教师 KL 可以作为评估指标。

本方案只有梯度统计与解析补偿，没有通过训练更新原模型，不能仅因用了反向传播就称为 QAT。

## 15. 12 GB 显存下的首个真实实验

模型优先选已有访问权限的 Llama-3.2-1B，并确认当前 ResComp 代码和依赖版本支持它；没有权重时先做小型随机 Llama 的接口 smoke test，随机模型结果不用于效果结论。模型来源：[模型卡](https://huggingface.co/meta-llama/Llama-3.2-1B)。不要直接从 7B 开始。

1B 参数的 16 位权重约占 2 GB，但实际峰值还包含激活、梯度图、工作区和统计矩阵，不能据此保证显存够。batch=1，梯度采集 seq_len=128 起步，稳定后到 512；一次一个模块、一个敏感度组，缓存放 CPU。

一个 d_in×d_in FP32 矩阵占 4d_in² 字节：d_in=2048 时约 16 MiB，8192 时约 256 MiB。H、C、分解及临时量可能同时存在。先选中部 block 的 o_proj，而不是高输入维度 down_proj。不要同时常驻教师和完整学生副本。

重要：如果前缀完全浮点，X_q=X_f，这只验证了对称输入情况下的任务引导，不能充分验证你想要的非对称补偿。正式小实验需要同一个已量化前缀。

实验步骤：

1. 保存原始权重与配置，确定中部一个 o_proj 为目标模块。
2. 在浮点教师上，用校准集记录目标输入 X_f、固定目标 Y₀和 G。
3. 用原版 ResComp 量化到目标模块之前的所有预定模块，保存这一个公共前缀。
4. 在公共前缀下采集 X_q，与教师按序列 ID 和 token 位置对齐。
5. 从同一 W₀起点，分别运行原版和加权版本；不能让后一个候选继承前一个的补偿权重。
6. 分别装入候选目标权重，保持前缀、下游浮点权重和其他条件完全一致，在独立验证集评测 CE/PPL、普通重建误差和加权重建误差。
7. 加权验证误差需要验证集自己的教师梯度，可在验证集独立采集；测试集梯度不参与量化或选择。CE 是首要验证指标，不要求用 J_s 选模型。

这是能在小资源上检验机制的最小实验，不是最终全模型 benchmark。

## 16. 数据与公平对照

小规模起步：固定一种文本数据，记录版本与抽样 ID。训练划分采样 32 条 × 512 token 用于校准，另取不重叠 16 条 × 512 用于验证。测试集完全独立，不根据测试结果选择 ρ、组数或补偿系数。这个规模只用于 pilot，最终采用足够规模的公开评测协议。

| 对照 | 要回答的问题 |
|---|---|
| 原始浮点模型 | 原模型质量与损失基线 |
| 原版 ResComp | 改动是否带来实际收益 |
| 新路径 + s=1 | 代码改动本身是否改变结果 |
| 每通道固定正数 | 第 6 节无效性条件是否在实现中成立 |
| 共享 token 权重（A） | 是否仅困难 token 权重就够 |
| 分组 token 权重（B） | 输出组信息是否带来额外收益 |
| 打乱后的权重 | 收益是否依赖敏感度与激活正确对应 |
| 等预算调优的 ResComp | 收益是否只是更多超参数搜索 |
| GuidedQuant / 有条件时 GPTAQ | 比已有任务引导与非对称补偿强多少 |

打乱对照在有效 token 之间置换权重并保持分布，不把 padding 混入。每个方法固定相同模型、位宽、数据、随机种子、量化网格、旋转、列顺序和评估上下文。

若新方法搜索 4 个 ρ，原方法也给相近数量的补偿系数候选，并报告校准时间。候选选择方案 C 必须与普通 MSE 选择、验证 CE 选择分别对照，避免把额外搜索收益误认为新度量收益。

第一阶段 W4A16，随后 W3A16；先不做 W2，以免极强扰动使局部敏感度近似难以解释。正式结果至少 3 个校准采样种子，报告配对差值。

## 17. 指标、判据与失败诊断

首要指标为 held-out mean next-token CE；PPL=exp(CE)，必须对总有效 token 的负对数似然求平均后再指数化，不能平均每段 PPL。其次记录任务准确率、J₀、J_s、峰值显存与总耗时（含梯度采集）。

“通过”分三层：

* 数学正确：有限差分、残差恒等式、KKT、全一退化、整体缩放不变性通过。
* 局部有效：固定前缀下候选模块降低独立数据 CE，多次抽样方向稳定，优于打乱权重。
* 全模型有效：同等量化配置、相同调参预算下，完整量化模型在未参与选择的测试数据取得更低 CE/PPL，并报告额外成本。

用逐序列配对 bootstrap 给测试 CE 差值估计区间，报告原始值而不是只说“显著”。只有 3 个种子不能支持广泛结论；小模型单数据集上的结果只能限定于该设置。

失败时按顺序检查：

| 现象 | 优先检查 |
|---|---|
| s=1 都不同 | 统计尺度、阻尼、量化网格、列序、缓存与冻结坐标 |
| 不同 s 得到相同 Q | 是否退化为行常数；是否忘记把 s 用到更新；量化网格是否太粗 |
| J_s 下降但 CE 变差 | 代理失配、梯度尖峰、局部近似失效；降低 ρ，检查留出集 |
| 校准有效、验证无效 | 样本过少、过拟合、数据分布和归一化 |
| 只有调 α 后有收益 | 是否超过基线搜索预算；可能主要来自补偿强度选择 |
| 显存不足 | 序列缩短、一次一个组/模块、CPU 缓存、检查未释放计算图 |

不要为了得到正结果删去失败的种子或只报告表现最好的层。

## 18. 你现在具体该做什么

本文不替你一次性写完量化器。建议按以下可验收任务推进：

**任务 1：完成已有 exercise_01.py。** 先实现 weighted_error 和 best_candidate，并通过已有 5 项测试。它只用于理解度量改变候选选择，不是大模型结果。

**任务 2：写 weighted_stats.py。** 用 PyTorch 构造小型随机 X_f、X_q、W₀、W 与非负 s，返回 Hraw、C。证明并数值验证 T=Hraw+C 和 RDX_qᵀ=WC+(W₀−W)T；比较显式 diag(s) 与列广播的结果。正式实现不要创建 N×N 的 D。

**任务 3：写 reference_step.py。** 按第 10 节使用 solve 写单行单步补偿。检查被量化坐标恰好满足约束、冻结坐标不变化、KKT 残差足够小。先不写 block/lazy update。

**任务 4：跑通原版。** 固定官方代码 commit、依赖版本、模型 revision、数据 ID，运行浮点和原 ResComp 小模型评估。实际入口及 CLI 参数必须按下载到本地的版本核对，本文件不编造尚未验证的训练命令。

**任务 5：采集一个模块梯度并接方案 A。** 先画/打印 s 的分位数、零值比例、最大值和有效 token 均值。确认梯度不是全零且样本对齐，再进入量化。

**任务 6：做固定前缀单模块对照，再加入方案 B。** 通过后才扩展多个模块和完整模型。

每次保留 config.json、metrics.json、代码 commit、校准样本 ID 和日志。结果记录字段建议：method、model_revision、bits、quant_group_size、sensitivity_groups、rho、clip、damping、seed、calibration_ids、validation_ce、test_ce、ppl、seconds、peak_vram。

旁边的 verify_weighted_math.py 是无需第三方依赖的独立代数检查脚本；它不是你的研究实现，也不读取或修改模型权重。运行它通过只能说明这里的几个公式与构造例子一致，不能证明真实模型有效。

## 19. 下一步的研究决策

首选提交给导师讨论的方案是 **B：固定浮点目标 + 分组、随 token 变化的梯度平方度量 + 对 Gram 和残差统计一致加权**。

首先回答“度量确实改变补偿并改善留出损失了吗”，然后才回答“是否有稳定的全模型优势”。若方案 A 已与 B 相同好，通道分组可能不是必要贡献；若只有 C 有效，则重点可能在候选选择；若打乱权重同样好，应怀疑收益来自数值正则化而非任务敏感度。

这三个结论都能指导后续研究，不能提前用数学推导替代实验答案。
