# 练习区

`exercise_01.py` 是加权平方误差和有限网格搜索练习，保留待实现函数。可在本目录运行 `python -m unittest test_exercise_01 -v`；未完成练习时失败属于预期。

`learn_load_model.py` 演示 tokenizer、模型前向和文本生成。实际量化代码在上一级目录，它不需要这里的空白 `model.py`。

`model.py` 是整理前就存在的空文件，保留供你练习。我们没有重新训练模型，也没有把实验实现藏在这个文件中。
