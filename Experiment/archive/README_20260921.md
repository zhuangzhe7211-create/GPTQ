## 研究问题的当前表述

在固定原始浮点输出为目标的非对称重建中，采用最终任务梯度构造的 token / 输出通道组度量，能否在可接受的校准开销下改善量化补偿？

“梯度加权输出误差”“通道分组”已有 GuidedQuant；残差强度自适应已有 MARR；更丰富的任务曲率与动态补偿还涉及 YAQA、KronQ、BaKron、REAL-Q。具体证据见检索记录。当前是待研究的组合假设，不命名为已成立的新算法。

## 进入实验前的检查点

- [ ] 自己推出有一个量化约束的二次问题，并能退化回 GPTQ。

- [ ] 能推出加权 H、C、T，解释为何不能只改 H。
- [ ] 能证明固定通道正权重的不变性和输入重标度等价。
- [ ] 能说清梯度平方是代理、哪些交叉项被忽略、哪些结论需要实验。
- [ ] 完成至少一个两维纸笔例子，并画出自己方案与 GuidedQuant / ResComp 的差别。

完成后再看小矩阵数值验证 → 少量核心代码 → 单模块 → 全模型。你负责推导与解释，我负责逐步讲解、检查符号和前提、指出错误；不默认把整套研究实现替你写完。
