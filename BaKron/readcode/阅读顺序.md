# BaKron 阅读顺序与代码状态

当前 `code/` 只有状态说明，没有 BaKron 官方实现，因此先按论文算法顺序阅读，不能编造源码文件入口。

1. [资料来源.md](../资料来源.md)：核对论文版本和代码公开状态。
2. 先复习 [GPTQ 阅读顺序](../../GPTQ/readcode/阅读顺序.md)，特别是单行逐列舍入、逆 Hessian/Cholesky 补偿。
3. 再看 [YAQA 阅读顺序](../../YAQA/readcode/阅读顺序.md)，理解双侧 Kronecker Hessian 与输入/输出反馈；BaKron主要加速这一类舍入问题。
4. 论文 §3.1：固定列主序 `vec(W)`、Kronecker 恒等式和 Cholesky 约定。
5. 论文 §3.2：从 `A ⊗ B` 上的向量化 GPTQ 得到 BaKron-naive，先确认它为何需要 `mn` 个顺序步骤。
6. 论文 §3.3：画出权重矩阵依赖图，理解同一反对角线为何能并行；这把顺序深度降为 `m+n-1`。
7. 论文 §3.4–§3.5：理解分治如何延迟并批量合并更新，再看它如何与反对角线并行组合成 BaKron。
8. 论文 §3.6–§3.7：逐项核对顺序深度、总计算量和等价性保证；区分“与朴素算法等价”和“找到全局离散最优”。
9. 论文 §4–§5：最后看局部/全局损失、Kronecker 因子选择以及反向传播 Hessian 的高效计算。这部分决定算法接收到什么曲率，但不是 BaKron 求解器本身。
10. 论文 §6 与附录：看 benchmark、证明和实验设置；等官方代码发布后，再补真实入口 → Hessian 构造 → BaKron 求解器 → 评估的代码路径。
