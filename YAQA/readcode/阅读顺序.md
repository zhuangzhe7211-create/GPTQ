# YAQA 代码阅读顺序

先理解 GPTQ/LDLQ 的单侧输入 Hessian，再看 YAQA 如何加入输出侧因子并以全模型 KL 为目标。论文应先读第 2 节背景、第 3.1 节双侧自适应舍入、第 3.2 节 Hessian Sketch A/B；代码仓库建立在 QTIP 上，第一轮只追踪 YAQA 改动。

1. [README.md](../code/README.md)：确认仓库目的、QTIP 基础和预计算 Hessian 的入口。
2. [hessian_llama/README.md](../code/hessian_llama/README.md)：比较 Sketch A 与 Sketch B 的运行条件；论文和代码都推荐资源允许时使用 Sketch B。
3. **[hessian_llama/get_hess_llama.py](../code/hessian_llama/get_hess_llama.py)**：看参数解析、A/B 分支、层范围和统计保存流程。
4. [hessian_llama/llama_hess.py](../code/hessian_llama/llama_hess.py)、[data_utils.py](../code/hessian_llama/data_utils.py)：看模型层、样本和分布式收集怎样组织。
5. **[custom_linear_A.py](../code/hessian_llama/custom_linear_A.py)** 与 **[custom_linear_B.py](../code/hessian_llama/custom_linear_B.py)**：对照论文 Sketch A/B，追踪输入因子与输出因子如何从前向/反向统计得到。
6. **[lib/algo/ldlq.py](../code/lib/algo/ldlq.py)**：读本仓库提供的 `LDLQ_2hess()`；重点看 `Lin`、`Lout` 如何产生输入侧与输出侧反馈。单侧 LDLQ 基线需回到 GPTQ/LDLQ 前置材料对照，本文件没有单独实现 `LDLQ()`。
7. [lib/utils/math_utils.py](../code/lib/utils/math_utils.py)：看 `block_LDL()` 和数值分解工具，确认传给舍入器的三角因子是什么。
8. **[lib/algo/finetune.py](../code/lib/algo/finetune.py)**：从 Hessian 文件加载开始，追踪 `Hin/Hout` → `Lin/Lout` → `LDLQ_2hess()` → 量化结果。
9. [quantize_llama/quantize_finetune_llama.py](../code/quantize_llama/quantize_finetune_llama.py)：看整层量化入口、不同模块的 Hessian 文件映射与保存流程。
10. 最后看 [hfize_llama.py](../code/quantize_llama/hfize_llama.py)、`eval/` 和 `qtip-kernels/`，理解导出、评估和推理；这些不影响第一遍掌握 YAQA 的数学核心。

## 核心文件具体做什么

| 文件 | 作用 |
|---|---|
| `hessian_llama/get_hess_llama.py` | Hessian 收集总入口，选择 Sketch A/B 并按层运行。 |
| `hessian_llama/llama_hess.py` | 为 Llama 模型组织逐层 Hessian 统计。 |
| `hessian_llama/custom_linear_A.py` | 实现 Sketch A 所需的自定义线性层统计。 |
| `hessian_llama/custom_linear_B.py` | 实现 Sketch B 所需的自定义线性层统计。 |
| `lib/utils/math_utils.py` | 提供 block LDL 等矩阵分解与数值工具。 |
| `lib/algo/ldlq.py` | YAQA 舍入核心；`LDLQ_2hess()` 同时使用输入、输出两侧三角因子。 |
| `lib/algo/finetune.py` | 加载双侧 Hessian、执行旋转/分解、调用舍入器并组织局部优化。 |
| `quantize_llama/quantize_finetune_llama.py` | Llama 量化总入口，负责模块遍历、Hessian 路径和结果保存。 |
| `quantize_llama/hfize_llama.py` | 将量化中间结果转换为可加载的 Hugging Face 模型。 |

第一轮跳过 CUDA 内核、端到端微调和评估细节。先把论文式 (3)–(6) 与 `LDLQ_2hess()` 对齐，再研究 QTIP 的码本和部署。
